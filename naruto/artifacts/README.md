# naruto

Headless, fast, iteration-friendly Naruto TCG (currently unreleased) simulator for collecting high-volume data from agent-driven simulations.

- Docs (Astro Starlight): https://gengur123.github.io/naruto-docs/ — published from the public [naruto-docs](https://github.com/Gengur123/naruto-docs) repo; the working copy is `docs/site` here
- Skills in `.claude/skills`: `dandori-lite`, `clickertrain`, and the official MoonBit skills
- Forks used by the workflow: [dandori-dex](https://github.com/Gengur123/dandori-dex), [usagui](https://github.com/Gengur123/usagui), [leptos-usagui](https://github.com/Gengur123/leptos-usagui), [shibapan](https://github.com/Gengur123/shibapan), [matchamill](https://github.com/Gengur123/matchamill)
